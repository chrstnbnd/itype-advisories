# Disclosure timeline

- **June–July 2026** — The seven issues were identified and reported to the
  affected downstream vendor through its coordinated vulnerability disclosure
  program.
- **July–September 2026** — The vendor triaged the reports and confirmed the
  findings.
- **August 2026** — CVE assignment was requested.
- **September 2026** — Because the affected component is supplied by a third
  party, CVE assignment was routed onward, and the affected-product scope was
  set to the iType library rather than any product that consumes it.
- **October 2026** — Seven CVE ID requests are open with MITRE, and these
  advisories were published to serve as their reference. No CVE ID has been
  assigned yet. IDs will be added here once assigned.

Monotype publishes no security contact, and iType is licensed across a wide
embedded base, so one upstream fix has to reach many integrators. Whether a
given product is exposed depends on whether it renders untrusted font programs,
as described in the README.

Monotype and any licensee are welcome to contact the researchers through this
repository for reproducers or further detail.

These advisories contain no exploit code and no weaponized proof artifacts.
Vendor communications remain confidential.
